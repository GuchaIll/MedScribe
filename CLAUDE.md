## Claude Code specifics

- Issue workflow in AGENTS.md is mandatory: check parent and sub-issues, new branch, plan doc in `docs/plans/` first, then push and open a PR with Changes / Plan / Test criteria.
- Pushing the branch and opening the PR at the end of an issue is pre-authorized. Merging, force-pushing, and closing issues are not.
